agent-signals

Measured signals of AI coding agents, as a language-neutral test corpus.

Your tool reads the screen of an agent and gives a state. This site holds 310 measured screens of 33 agents, and the state that a reader must give for each screen. Test your reader against them.

Start here: test a reader in four steps

  1. Learn the states

    A screen has one of seven states, for example IDLE, BUSY and PERMISSION.

    Read the seven states

  2. Find the screens

    Each state has measured screens. Each screen gives the agent version and how it was made.

    Read the screens of each agent
    Read the states by agent

  3. Test your reader

    Load the corpus with the Go library, with the Python library, or as files. Write one table test.

    Test your reader against the corpus

  4. Read the facts

    93 facts tell what was measured behind the screens: hooks, session files, and what a tool must not do.

    Read the facts
