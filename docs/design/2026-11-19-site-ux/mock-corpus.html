Corpus

The corpus holds 310 measured terminal screens of 33 agents. Each screen gives the state that a reader must give for it.

Test your reader against the corpus

The states

Each number is a link to the screens with that state.

  • IDLE A framed input box waits for a message. 141 screens
  • BUSY The agent works on a turn. 41 screens
  • PERMISSION A dialog waits for an answer. 82 screens
  • TRUST The folder-trust question. 10 screens
  • DIALOG_OVER_BOX A dialog draws above a live input box. 2 screens
  • NO_BOX The agent has not drawn its input box yet. 24 screens
  • UNKNOWN The reader cannot read the screen. Send no key. 10 screens

A chip with a filled background is a state that waits for an answer of the user. A chip with a dashed border is UNKNOWN. Read the format of a screen for each field.
