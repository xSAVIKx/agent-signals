Three kinds of signals

  • Terminal screens

    The exact text of an agent pane, as tmux capture-pane gives it. Each screen has the state that a reader must give for it.

    {{.Screens}} screens of {{len .Agents}} agents.

    Read the corpus of screens

  • Hook payloads

    The events that an agent sends to a hook script: a permission request, a notification, the start and the end of a turn. The facts give the order of the hooks and the fields of each payload.

      {{- $o := .Out}} {{- range .Hooks}}{{if hasFact .}}
    • {{factTitle .}}
      • {{- end}}{{end}}

  • Session files and open files

    The files that an agent writes and keeps open: the pid file, the rollout file, the chat database. A tool can read them without the screen.

      {{- range .Files}}{{if hasFact .}}
    • {{factTitle .}}
      • {{- end}}{{end}}

The corpus holds the screens now. The facts describe the hooks and the files. Log lines are not in the repository yet.
