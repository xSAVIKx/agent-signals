How to pin a release

  1. Select the tag of the package that you use.
  2. For the data, copy corpus/, schema/ and facts/ from a corpus-v tag.
  3. For Go, run go get github.com/xSAVIKx/agent-signals/go@v{{(index .Items 1).Version}}.
  4. For Python, run pip install "agent-signals @ git+https://github.com/xSAVIKx/agent-signals@python-v{{(index .Items 2).Version}}#subdirectory=python". The package is not on PyPI.

The versioning rules tell which change makes a major, a minor or a patch release. Read Versions. All releases are on the releases page on GitHub.
